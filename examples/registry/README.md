# Illustrative registry

These examples describe a fictional settlement system.
They do not contain discovered facts about an existing system.
All repository identities, paths, revisions, source URLs, owners, and contract declarations are invented.
The example source files do not exist.
The `documented` status illustrates the format only.
It does not assert evidence or actual execution.

The files show all repository classifications, contract types, and source types.
They also show shared implementation repositories and separate deployment repositories.
The GraphQL candidate shows a documentation gap without verified claims.

Keep these examples separate from the empty default registries.
Before reuse, replace all invented entries with evidence from the target system.
Keep referenced IDs consistent across files.
An example registry grants no executable operations.
The `tools.yaml` file is empty.

Use [the registry guide](../../registry/README.md) for field definitions and validation rules.
