1. Auto Refresh - As an user, upon cashflow result based on specific query from cashflow blotter, they want any change happened on the cashflow to be reflected on cashflow blotter screen automatically.
2. Limitation on count of cashflow query result from DQSL. - Currently it is only hundreds of cashflow can be captured from one batch query from DQSL, going forward user want no limitation on the count of cashflow query result from DQSL.
3. Scenario Priority - Column 'Senario Priority' indicate priority in case one cashflow fulfil multiple scenarios, cashflow will apply to scenario with higher priority. for example one cashflow belong to CLS netting, while it also fulfiil ad-hoc static table, in this case the cashflow will be treated as CLS netting because CLS netting has higher priority than ad-hoc netting.

## Agreement on the netting
