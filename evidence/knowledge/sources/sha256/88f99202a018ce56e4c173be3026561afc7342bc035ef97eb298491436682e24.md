# GUI Guide

- Conditions to allow the netting actions: 1. Cashflow not in "Settled" nor "Released": e.g. in 'Projected'/'Queued'/'Pending'/'Validated'/'Ready'/'Waiting'/'Hold' status 2. Netting Id is blank for the selected cashflows
- Conditions to do the un-net actions - Cashflow not in "Settled" nor "Released": e.g. in 'Queued'/'Pending'/'Validated'/'Hold' status - Netting id is not blank

Note: Once the cashflow is settled and release to downstream, it is not allowed to do net or unnet in Ratan.

Ratan need to take these new version & cashflow event and auto un-net the previous netting result.

# 'Settle as Gross' action

### Requirement Overview

- When cashflows are stuck in 'waiting netting' or 'pending another leg', users can have action option to "Settle as Gross".
- User may want to "Settle as Gross", when there is no need to do netting, e.g. only 1 cashflow is 'waiting netting' or 'pending another leg', or the user does not want to net the multiple cashflows anymore even they are under 'waiting netting' or 'pending another leg'.
- Settlement ops can select 'Settle as Gross' action after right click the cashflow which is under 'Pending Netting' or 'Pending Another Leg' status. This user is the initiator for this change "from Net to Gross", which can be considered as 'Settle as Gross' action '**Maker'**. - Cashflow will be published to multi exception checking - Exception '**Settle As Gross****' **will be generated together with other exceptions( if any), the exception '**Settle As Gross**'** **would be only visible to checker(exception maker/checker concept) which means exception fix maker can't see this exception.
- Exception fix Checker can check and approve this 'Settle As Gross' exception via multiple exceptions approval. This would be the second user get involved in this '**Settle As Gross**' change., which can be considered as 'Settle as Gross' action '**Checker**'. - If Checker agrees to settle as Gross, after he/she approve the multiple exception, the cashflow status updates to "Ready" - If Checker does not agree to settle as Gross, he/she can adhoc netting the grossed cashflows.
