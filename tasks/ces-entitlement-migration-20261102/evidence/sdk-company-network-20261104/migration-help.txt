usage: python -m ai_sdlc_workbench.entitlement_coverage [-h] --config CONFIG
                                                        [--mode {live,replay}]
                                                        [--output OUTPUT]
                                                        [--resume RESUME]
                                                        [--user-limit USER_LIMIT]
                                                        [--open]

Run scoped EMS2-to-CES reconciliation from project-owned configuration. This
optional helper supports the inspected collection and matrix contracts only.
It does not infer data-policy equivalence or a complete EMS2 account
directory.

options:
  -h, --help            show this help message and exit
  --config CONFIG
  --mode {live,replay}  Use supplied response mocks by default; live
                        collection requires an explicit selection
  --output OUTPUT
  --resume RESUME
  --user-limit USER_LIMIT
                        Bound a diagnostic run; omitted accounts remain
                        unassessed
  --open
