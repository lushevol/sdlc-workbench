# Checklist: Test Case Review Checklist

> The purpose of this document is to ensure that all appropriate testing techniques have been included in the planned test cases.

---

## Main Description

- The Test Manager must review the test cases using the Test Case Review Checklist to ensure that all appropriate
 testing techniques have been included.
- The Product owner must approve the completed Test Case Review Checklist
- Refer to Test Case Design Techniques for a complete list of testing techniques to be applied during test planning.
- This activity must be performed for **all releases** and at a minimum once every three (3)
 months.
- In addition to this, the Regression Test Cases needs to be reviewed every six (6) months using Test Case Review
 Checklist.
