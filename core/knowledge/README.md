# Knowledge authoring resources

This directory supplies [schemas](schemas/) and [templates](templates/) for domain records and SDLC documents.
These resources support the Workbench harness. They are not business-domain knowledge.
Generated workspaces receive these resources without runtime Python source.
Use [the knowledge contract](../../knowledge/README.md) for domain content and governance rules.
Knowledge records describe requirements, intent, and ideal target behavior.
Keep actual implementation and conformance findings in independent task gap Markdown.
