## [2.10.0] (2026-05-22)

### Features

* **confluence_read_page / confluence_get_page**: Add `body.export_view` to expand parameters — fixes tab-content rendering for pages that use the Confluence Tabs macro
* **confluence_get_page**: New ID-based tool to fetch a page directly by numeric ID (view, storage, export_view body formats)
* **confluence_find_page**: New tool to find a page by space key and exact title via CQL
* **confluence_get_page_children**: New tool to list child pages of a given page ID
* **confluence_list_spaces**: New tool to list Confluence spaces (global, default limit 50)
* **confluence_get_space**: New tool to get details of a space by key
* **confluence_delete_page**: New tool to delete a page by ID with mandatory title-confirmation safety check
* **confluence_add_comment**: New tool to add a page-level comment in Confluence Storage Format
* **confluence_get_labels**: New tool to retrieve all labels on a page
* **confluence_add_label**: New tool to add a label to a page
