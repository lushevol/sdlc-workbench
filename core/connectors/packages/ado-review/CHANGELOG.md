## [1.0.0] - 2025-01-01

### Added
- `post_pr_comment` — Post AI-assisted review comments on PR file lines
- `delete_all_pr_review_comments` — Delete all AI-generated comments from a PR
- `repo_review_pr` — Automated pull request code review with inline comments
- `repo_pr_diff` — Retrieve pull request diff
- Prompts: `review-pr`, `analyze-pr-diff`, `delete-pr-review-comments`
