# @sc-node-mcp/ado-sprints

Azure DevOps sprint, iteration, and capacity MCP server — **8 tools**.

## Tools

| Tool | Description |
|------|-------------|
| `work_list_iterations` | List iterations (sprints) in a project |
| `work_create_iterations` | Create new sprint iterations |
| `work_list_team_iterations` | List iterations assigned to a team |
| `work_assign_iterations` | Assign iterations to a team |
| `work_get_iteration_capacities` | Get capacity for all teams in an iteration |
| `work_get_team_capacity` | Get capacity for a specific team in a sprint |
| `work_update_team_capacity` | Update a team member's capacity for a sprint |
| `work_get_team_settings` | Get team settings |
