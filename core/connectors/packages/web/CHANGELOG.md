# Changelog

All notable changes to `@sc-node-mcp/web` are documented here.

## [1.2.0] - 2026-06-16

### Added
- `web_crawl_browser` tool — crawls JavaScript-rendered websites (React/Angular/Vue SPAs) using the system-installed Chrome or Edge browser (`--headless=new --dump-dom`). Supports the same four output modes as `web_crawl`: `urls`, `summary` (default), `full`, `links`. Configurable `maxDepth`, `maxPages`, and `delayMs` (default 1000ms for JS rendering time). Requires Google Chrome or Microsoft Edge installed; auto-detects executable across macOS, Windows, and Linux.
- MCP prompt `web-crawl-browser` for guided browser-crawl workflows

## [1.1.0] - 2026-06-16

### Added
- `web_crawl` tool — crawls a website from a seed URL following same-domain links (BFS). Supports four output modes: `urls` (URL list), `summary` (URL + title + 500-char snippet), `full` (URL + title + full text), `links` (URL + outbound link graph). Configurable `maxDepth` (default 3), `maxPages` (default 50), and `delayMs` (default 500ms) parameters.
- `cheerio` dependency for HTML parsing and link extraction in `web_crawl`
- MCP prompt `web-crawl` for guided crawl workflows

## [1.0.0] - 2026-06-16

### Added
- `web_search` tool — searches DuckDuckGo Lite and returns structured results (title, URL, snippet)
- `web_fetch` tool — fetches and strips any HTTPS URL to plain text (max 15,000 chars)
- Python subprocess bridge (`scripts/search-ddg.py`) to bypass DuckDuckGo TLS fingerprinting (JA3) that blocks Node.js
- Auto-detection of Python 3.x executable (`python3` → `python` → `py`)
- Automatic proxy detection via `detectProxyFor('html.duckduckgo.com')` — including `127.0.0.1:9000` SSH tunnel
- MCP prompts for guided `web_search` and `web_fetch` workflows
- Full Vitest test suite with `child_process` mocks for Python bridge and `node:https` mocks for web_fetch
