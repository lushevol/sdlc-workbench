# 1.0.0 (2025-05-12)


### Features

* initial release of `@sc-node-mcp/sonar` MCP server
* `sonar_search_projects` — Search or list SonarQube projects by name or key
* `sonar_get_branches` — List all analysed branches for a project
* `sonar_get_quality_gate_status` — Check quality gate pass/fail status for a branch or pull request
* `sonar_get_issues` — Search for bugs, vulnerabilities, and code smells
* `sonar_get_hotspots` — List security hotspots requiring manual review
* `sonar_get_measures` — Retrieve code quality metrics (coverage, bugs, tech debt, ratings)
* bearer token authentication via `SONAR_TOKEN` environment variable or CLI arg
* pre-configured for Standard Chartered's SonarQube instance (`https://sonarqube.vx.standardchartered.com`)
* integration into `@sc-node-mcp/unified` server (conditional registration when token provided)
