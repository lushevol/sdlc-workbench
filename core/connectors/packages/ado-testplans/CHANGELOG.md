# Changelog

All notable changes to `@sc-node-mcp/ado-testplans` are documented here.

## [1.0.0] - 2025-01-01

### Added
- `testplan_list_test_plans` — List test plans with optional active-only filter
- `testplan_create_test_plan` — Create a test plan with name, iteration, and optional dates
- `testplan_list_test_suites` — List test suites within a test plan
- `testplan_create_test_suite` — Create a test suite under a parent suite
- `testplan_add_test_cases_to_suite` — Add test cases to a suite by ID
- `testplan_list_test_cases` — List test cases in a suite
- `testplan_create_test_case` — Create a test case work item with optional priority and steps
- `testplan_update_test_case_steps` — Update steps of an existing test case
- `testplan_show_test_results_from_build_id` — Retrieve test results for a build
- Prompts for all 9 test plan tools
