# Workbench integration

Use [the native connector guide](../../docs/CONNECTORS.md) for this project.
Install dependencies from the Workbench root and maintain variables in its root `.env` file.
Agents invoke connectors through Workbench CLI or MCP resource grants.
The imported guide below describes the original standalone project and its release workflow.

# Overview

This project demonstrates a modular MCP (Model Context Protocol) server for Azure DevOps, exposing work item and repository management as discoverable, automatable tools. The server provides unified access to Azure DevOps APIs through a standardized protocol, enabling seamless integration with editors and automation tools.

## Key Features

- **Unified MCP Server:** Single entry point for Azure DevOps, Confluence, Email, Web Search, Nexus IQ, and SonarQube
- **Work Item Management (29 tools):** Query, create, update, link, and comment on work items
- **Repository Operations (20 tools):** Manage repositories, branches, pull requests, and commits
- **Pipeline Operations (14 tools):** Trigger, monitor, and manage Azure DevOps pipelines and builds
- **Sprint & Capacity (8 tools):** Manage iterations, assign sprints to teams, get and update capacity
- **Test Plan Tools (9 tools):** Create and manage test plans, suites, and test cases
- **Search Tools (2 tools):** Full-text search across code and work items
- **Automated PR Review (4 tools):** AI-driven code review with comments posted directly to PR lines
- **Email Integration:** Send emails via Outlook automation (no SMTP configuration needed)
- **Teams Integration:** Send messages via Microsoft Teams desktop app (no webhook or API setup required)
- **Web Search & Crawl (4 tools):** Search DuckDuckGo Lite (no API key), fetch any URL as plain text, and crawl static or JS-rendered websites via Python subprocess bridge — bypasses TLS fingerprinting
- **Confluence Integration (15 tools):** Create, update, search, read, get page ID, list pages, manage spaces, comments, and labels
- **SonarQube Integration (6 tools):** Query code quality, security hotspots, issues, and metrics from SonarQube
- **Nexus IQ Scanning (2 tools):** Scan local npm dependencies for vulnerabilities (Node.js/npm/yarn projects only); automated multi-phase remediation of direct and transitive CVEs
- **Context Management (4 tools):** Named workspace contexts auto-fill project/team/repo across all tools; stored in `~/.sc-node-mcp-context.json`
- **Modular Architecture:** Clean separation of concerns with independently-versioned packages


# NPM Registry Configuration

To install or publish SC Node MCP packages, you must configure npm to use the Standard Chartered Artifactory registry.

**Recommended (for all packages):**

```bash
npm config set registry https://artifactory.global.standardchartered.com/artifactory/api/npm/npm-release/ --global
```

This sets the default registry for all npm operations. If you only want to set the registry for the @sc-node-mcp scope, see the Installation Guide.
