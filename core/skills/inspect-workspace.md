# Inspect a workspace

Required capabilities: `knowledge.search`, `knowledge.read`, `repository.status`, `testing.list`.

1. Read the workspace status and resource operations.
2. Select the resource and environment for each operation.
3. Search the knowledge resource for the requested behavior.
4. Read each cited source before describing its rule.
5. Inspect the repository status and available test suites.
6. State confirmed facts, inferences, and unresolved questions separately.

Keep source identity and action IDs in the result.
A search miss does not prove that a rule does not exist.
An available test suite does not prove coverage or successful execution.
