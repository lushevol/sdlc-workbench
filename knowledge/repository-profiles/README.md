# Repository profiles

Use `type: RepositoryProfile` to describe a registered repository.
Describe intended responsibility, components, contracts, dependencies, entry points, and validation commands with their source authority.
Keep implementation inventories, observed behavior, and differences in independent task gap Markdown.
A profile does not grant execution access.
Use [the template](../../core/knowledge/templates/repository-profile.md) and [the standards](../README.md).
