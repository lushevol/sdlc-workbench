# Background

As part of the CCS / CLS-related enhancement, the business has requested an extension of the existing Swap Agent setup to support settlement of principal exchange via the Swap Agent model for selected clients.

# Requirement

**AS-IS: **Under the current setup, Swap Agent coupon and interim MTM cashflows are netted and SWIFT-suppressed in RATAN. Other Swap Agent cashflows follow the standard settlement process, and SWIFT messages are generated by RATAN

**TO-BE: **Under the expected enhancement, principal exchange cashflows, including initial/final exchange, should also be eligible for the Swap Agent settlement model. These cashflows should follow the similar handling as existing Swap Agent coupon / interim MTM flows, meaning they should be netted and SWIFT-suppressed in RATAN

- Scope: - Product: CCS - Counterparty: configurable in static or rule setup. - Payment Type: Below are the Swap Agent payment type values that RATAN has received for Stella CCS products. Business confirm action is required on whether any of them should be excluded from the netting rule. - [ ] Initial Notional - [ ] Final Notional - [x] Coupon - [x] Interim MTM

- Indicator for Swap Agent Cashflow: - Murex cashflow: Murex Product Strategy = 'SWAP_AGENT' - Stella cashflow: Swap Agent ID exists
- Netting Details - For selected clients, swap agent cashflow with different payment type should be netted together - Murex and stella cashflow can be netted together - Netting resultant payment type value: Swap Agent Netting - Existing SAL coupon netting and SAL MTM netting will continue to cover out-of-scope clients - Compared with existing netting types, Swap Agent netting should be given a higher priority than SAL MTM netting - ![image-2026-10-7_16-26-5.png](attachments/image-2026-10-7_16-26-5.png) - Netting date & time: VD 1:00 GMT
- Swift Suppression: both netting resultant and single cashflow (hit swap agent auto netting rule but has no other cashflow to net with) are expected to be swift suppressed.
- Accounting generation will follow the same as existing process

# Dependencies

Auto-netting and SWIFT suppression rely on the correct Swap Agent indicator. Incorrect or missing indicator values from upstream may result in unintended payment release.
