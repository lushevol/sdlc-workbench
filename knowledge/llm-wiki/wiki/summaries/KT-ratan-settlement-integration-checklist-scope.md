# RATAN Settlement Integration Checklist Scope

The selected 2026 checklists span inter-entity rate lookup, SSI usage APIs, Last Mile Checker, Korea and Uber adoption, central monitoring, manual entities, Auto DVP, precious metals, and CES extension. Each entry has its own scope and dependencies; the collection is not one unified release contract.

The inter-entity request describes a scheduled rate lookup and three retries, but gives no scheduler timezone and links to a UAT endpoint. SSI usage requests changes to an existing query API and a new BCS daily-usage API, while country and product scope remain unspecified. The Last Mile Checker entry is a placeholder without detailed validation rules or an external ACK/NACK contract.

Later entries name Korea product and interface scope, Uber entities and products, manual-entity activation targets, and Auto DVP taxonomies and inputs. Precious-metal 26C generation and the CES extension still lack mappings or entitlement predicates. No checklist “request” or status proves deployment, testing, or activation.
