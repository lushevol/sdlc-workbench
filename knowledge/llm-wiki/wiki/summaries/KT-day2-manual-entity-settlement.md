# Manual-entity settlement onboarding and regional controls

> **Source status:** Candidate/draft. Referenced spreadsheets, static sign-offs, rollout, and current settings were not verified.

The roster changes from Botswana to Qatar in a February 2026 scope and includes country and entity rows that must not be counted as the same unit. Release cutoffs vary by named entities; supplied Razor currency/shifter settings apply to selected rows, with a VD-1 business-day, 18:00 GMT fallback for missing configuration in the Qatar, Tanzania, and Bangladesh scope. These source values do not prove present configuration. [ME-01](../../../records/candidates/operations/KT-day2-manual-entity-settlement.md#me-01--dated-entity-and-release-cutoff-scope)

Other proposals cover country currency mappings, precision, accounting zones, DVP/NSTP rules, settlement suppression, SWIFT lists, and onboarding prerequisites. Later notes set NGN and NGB precision to two decimals, superseding the older NGN zero-decimal proposal. NGB uses `ROUNDING_OFF`. Open checklist rows and legacy `LOANID` text remain unresolved.
