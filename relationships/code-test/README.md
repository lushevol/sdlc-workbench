# Code to test relationships

Retain repository revisions, inspected code, test cases, assertions, and their evidence identities.
Keep assertion mappings separate from actual execution results.
Passing command status does not establish verified behavior.
The [behavior review guide](../../docs/BEHAVIOR_REVIEW.md) defines declared assertion links and retained execution-source checks.
Their business verification result remains `NOT_VERIFIED`.
Complete assertion-level verification requires further implementation.
